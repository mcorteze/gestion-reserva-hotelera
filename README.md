# Gestion Reserva Hotelera

Sistema de gestion de reservas para el Hotel Pacific Reef, desarrollado bajo la metodologia Scrum.

## Estructura del proyecto

- `frontend/`: aplicacion web (React + Vite)
- `backend/`: API REST (Node.js + Express)
- `docs/`: Project Burndown, Sprint Backlog, Roadmap y demas artefactos de planificacion

## Como levantar el proyecto

### Backend

```
cd backend
npm install
npm run dev
```

### Frontend

```
cd frontend
npm install
npm run dev
```
